Speaking Script

"Good afternoon mentors and panel. Today our team is proud to present Smart ATS, an enterprise-grade Applicant Tracking System built on a modern, decoupled architecture with Node.js Express, a normalized MySQL database, and a responsive React Vite frontend."

"As Team Lead and Principal Architect, I spearheaded the core foundational infrastructure. Here are the primary engineering pillars I implemented:

  • Normalized Database & State Machine: Designed a fully normalized schema supporting rigorous recruitment state transitions (APPLIED → SCREENING → INTERVIEW → SELECTED → OFFERED → REJECTED) with automated audit logging triggers.
  • Zero-Trust RBAC & JWT Security: Engineered strict role-based access controls across three distinct actor roles: ADMIN, HR, and CANDIDATE. Unauthorized privilege escalation is prevented at the router middleware level.
  • Secure File Isolation: All candidate resumes are stored in isolated server directories with randomized filenames and strict download verification—preventing public file exposure.
  • Automated Quality Assurance: Authored a comprehensive Jest test suite covering RBAC enforcement, candidate withdrawal boundaries, and zero-division analytics safety, currently passing at 100% green (12/12 tests).

Anticipated Questions & Best Answers

Q: How do you prevent candidates from accessing other candidates' resumes or stages?
A: (Lokesh / Meghana) Every file download and profile endpoint validates the JWT token. The SQL query strictly joins against req.user.id, and only authenticated users with role HR or ADMIN can view cross-candidate records.

Q: How did you manage git merge conflicts during team integration?
A: (Lokesh) We established strict module ownership in separate JSX files. When shared files like App.css or the Pipeline board had overlapping improvements, we reviewed diffs together, combined complementary CSS rules, and ensured the automated test suite passed before merging into main.
